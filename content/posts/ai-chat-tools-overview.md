想在自己的网站里用上 AI 对话，其实有非常多成熟的开源选择。这里做一个速览。

## 本地推理引擎

- **Ollama**：一条命令在本地跑开源大模型（Llama、Qwen、DeepSeek 等），提供标准 HTTP API；
- **llama.cpp**：极致轻量的推理引擎，适合低配置设备。

## 对话前端 / 全栈方案

- **LobeChat**：颜值极高的开源聊天界面，支持插件与多模型；
- **Open WebUI**：功能齐全的自托管聊天平台，与 Ollama 无缝配合；
- **NextChat**：轻量、易部署，适合个人使用。

## 集成到个人站点的思路

```text
浏览器 → 站点 /api/chat 接口 → 本地/云端模型服务 → 流式返回
```

本站的对话页面就是按这个架构预留的：前端界面已经就绪，后端只需在 API 路由里接上任意一个模型服务即可。

后续教程会手把手演示接入过程，敬请关注。
